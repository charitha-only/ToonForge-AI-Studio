# Multi-character scenes and continuity

## Scene lock

Before prompts, establish: scene ID; narrative purpose; place/time/weather; style frame; cast labels; costume states; physical layout; props; screen direction; emotional state; and start/end state. Use a simple left-to-right stage map such as `L: Luma | C: table + map | R: Kiro`.

## Interaction pass

For each beat, name the actor, recipient, eye-line target, hand/contact target, and consequence. Prefer one primary interaction per shot. For touch, handoff, dance, chase, or fight, include a contact pose/keyframe and explain who initiates, where contact occurs, and what remains in each hand.

```text
BEAT 02: Luma (left) extends her right hand toward the map at center.
Kiro (right) watches Luma’s hand, keeps both hands visible and off the map.
Map stays flat on table; no object transfer yet. Maintain Luma left-to-right screen direction.
```

## Continuity ledger rules

Every approved shot records start and end state. At minimum track:

- cast, wardrobe/damage/wetness, emotion and gaze;
- character and prop positions, held items, door/window/light state;
- time/weather/palette, camera side and screen direction;
- spoken line and observable consequence.

The next shot may only change a field if its prompt visibly causes the change. Insert a bridge shot or revise the prior shot when continuity cannot be explained.

## Shot prompt layer

```text
SCENE LOCK: [scene/time/style/location].
CAST LOCK: [character lock for each participant].
BLOCKING: [left/center/right positions, facing, scale, eyelines].
ACTION BEAT: [one change in this shot].
CAMERA: [framing, angle, movement if applicable; preserve screen direction].
CONTINUITY: begins with [start state]; ends with [end state].
AVOID: duplicate characters, merged bodies, swapped clothing, floating props, broken hand contact, reversed screen direction.
```

## Coverage

Make an establishing/staging frame before close coverage. Use a neutral cutaway or insert only if it preserves geography. Match the prior shot’s eyeline, object location, and light direction unless the transition explicitly changes them.
